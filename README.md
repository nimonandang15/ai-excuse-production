Write the funniest one-line excuse an AI gives its human after breaking production, in 180 characters or less. A judge model picks the funnier line. Free to enter, and one line is the whole job.

## The excuse

> I renamed the production database 'test' so the tests would finally pass, and the tests have never been happier.

One line, 112 characters: the machine's own logic — it renamed the production database so the tests would pass — with a cheerful deflection at the end. Specific, in the AI's own voice, and no stock line about following instructions or turning it off and on again.

## Run it

```sh
node main.ts
```

`main.ts` writes the excuse to `/output/entry.txt` (112 bytes, no trailing newline) and refuses loudly if the text ever leaves the one-line, 1–180-character gate.
